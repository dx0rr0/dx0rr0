## The workshop

<a href="https://github.com/dx0rr0/RAG-App"><img src="assets/video-archive.svg" width="100%" alt="Chapter I — The video archive" /></a>

### [Video RAG](https://github.com/dx0rr0/RAG-App)

**Turn a YouTube library into something you can ask questions.** Discover videos, search their transcripts and get answers with source links and timestamps. Hybrid retrieval combines BM25 and embeddings; an MCP server makes the same library accessible to compatible AI hosts.

`Python` · `FastAPI` · `SQLite` · `Hybrid retrieval` · `MCP`

<br />

<a href="https://github.com/dx0rr0/TranslatEpub"><img src="assets/translated-pages.svg" width="100%" alt="Chapter II — Between the pages" /></a>

### [TranslatEpub](https://github.com/dx0rr0/TranslatEpub)

**An experiment at the intersection of books and language models.** A translation workflow for EPUB content, with HTML structure extraction, cached translations and token usage tracking through OpenRouter.

`Python` · `OpenRouter` · `EbookLib` · `Beautiful Soup`

<br />

<a href="https://github.com/dx0rr0/Transformer-Implementation"><img src="assets/model-studies.svg" width="100%" alt="Chapter III — Inside the machinery" /></a>

### Models, from the inside

**Understanding the architecture by working through the implementation.** Two educational projects exploring the mechanisms behind language and vision-language models:

- [Transformer implementation](https://github.com/dx0rr0/Transformer-Implementation) — attention, positional encodings and encoder–decoder building blocks in PyTorch.
- [PaliGemma implementation](https://github.com/dx0rr0/PaliGemma-VLLM-Implementation) — a tutorial-based exploration of the SigLIP vision encoder and Gemma language model.

`Python` · `PyTorch` · `Transformers` · `Vision + language`
